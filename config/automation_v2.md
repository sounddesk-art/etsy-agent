# Etsy Agent V2

Pipeline: Generate -> Repurpose -> Upload

## Goals
- Batch-first and token-efficient.
- Create coherent mini-collections.
- Keep Etsy publishing manual; automation creates drafts only.
- Human curation gate before upload/publish.
- Reuse one visual across multiple low-risk digital product formats.

## Core series
1. Cozy Animals
2. Landscapes
3. Moon / Zodiac / Celestial
4. Botanical / Sun Symbolism

## Token efficiency
- One planning call per batch/series.
- Shared style brief per series.
- Shared metadata templates.
- Generate compact JSON manifests.
- Reuse tags/description fragments.
- No repeated market research inside a batch unless explicitly requested.
- Only approved assets enter repurposing/upload.

## V1 product derivatives
- Printable wall art
- Greeting card printable
- Postcard printable
- Bookmark printable when composition fits
- Multi-art bundle after 3+ coherent designs exist

## Review gate
Every asset gets status: queued -> generated -> approved/rejected -> repurposed -> uploaded.
Only approved assets may become Etsy drafts.
